## Como joga
É versátil, com **pulos para todo lado**: tem **3 pulos no ar** (o Juba tem 1), um projétil leve e golpes fáceis de emendar. É a personagem certa para quem gosta de ficar no ar.

**Mecânica própria: "Quique".** Se ela cair em cima da cabeça de alguém, **quica**: o adversário leva um pouquinho de dano, ela ganha os pulos de volta e sobe de novo. Com isso dá para fazer combos de pular de cabeça em cabeça.

## Golpes
| Golpe | Ideia |
|---|---|
| Jab 1 · 2 · 3 | Bicadinha, bicadinha e **cabeçada de topete** |
| Forte frente | **Estrelinha**: roda de ginástica acertando com os pés |
| Forte cima | **Mortal** chutando para cima |
| Forte baixo | **Espacate**: abre as pernas rente ao chão e acerta dos dois lados |
| Aéreos | Neutro: **parafuso** (gira em volta de si) · frente: chute de tesoura · trás: rabada · cima: cambalhota · baixo: **pisão de quique** |
| Especial neutro | **Semente de girassol**: cospe uma semente rápida e reta (projétil leve, sai em sequência de até 3) |
| Especial lado | **Bala de canhão**: se enrola numa bolinha e é lançada para o lado |
| Especial cima | **Trampolim**: três pulos seguidos, cada um mais alto (é a recuperação; a cada pulo ela dá uma nota para si mesma) |
| Especial baixo | **Bomba!**: mergulha de bunda e, quando bate no chão, quica e joga quem estiver perto para cima |
| Agarrão | Segura com os pés e arremessa com um mortal |

## Extras
- **Projétil próprio:** semente de girassol (2 quadros).
- **Comemoração (3 poses):** quica → aterrissa num pé só, braços para cima → mostra a placa com "10" desenhado (sem texto: placa com dois traços).
- **Descanso:** sentada balançando as perninhas, comendo semente.
- **Pendurado:** pendurada pelo **bico**, com as perninhas balançando.
