# Arte

- `prompts/`: prompts usados para gerar arte (um arquivo por pedido).
- `conceitos/<personagem>/`: imagens geradas, com um `.json` ao lado (prompt e parâmetros). Tudo aqui é **conceito** até o criador aprovar.

Como gerar: siga `prompts/ROTEIRO_CHATGPT.md` (ChatGPT, sem custo extra). Detalhes do fluxo em `.claude/skills/gerar-arte/SKILL.md`.
