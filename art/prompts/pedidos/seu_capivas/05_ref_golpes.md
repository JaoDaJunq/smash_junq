# Seu Capivas — 05 · Referência dos golpes (3 quadros por golpe)

Para cada golpe: **1) preparo** (antecipação exagerada, puxando para trás), **2) impacto** (corpo todo esticado no ponto de acerto), **3) recuperação** (voltando para a guarda). Referência para eu copiar ângulos; não precisa separar peças.

**Na conversa do Seu Capivas, anexe:** `art/conceitos/seu_capivas/folha_v1.png`. Mande **uma mensagem por bloco** (3 golpes por imagem fica mais fiel).

## Modelo da mensagem

```text
Folha de animação do Seu Capivas (o mesmo da folha anexada), estilo sumô de tiozão de clube, de perfil para a direita, com 3 golpes, um por linha. Cada linha tem 3 quadros lado a lado: 1) preparo exagerado, 2) momento do impacto com o corpo todo esticado e uma linha de movimento curva mostrando o caminho do golpe, 3) recuperação voltando para a guarda. Mesmo tamanho em todos os quadros, linha de chão nos golpes de chão. Fundo branco liso, número pequeno embaixo de cada quadro, nome do golpe à esquerda de cada linha.
Golpes:
<COLE AQUI OS 3 GOLPES DO BLOCO>
```

## Blocos

**Bloco 1 → `ref_golpes_1.png` (chão)**
```text
A) Jab: tapa de sumô com a mão espalmada para a frente.
B) Golpe para a frente: empurrão de barriga, dá um passo e joga a barriga para a frente.
C) Golpe para cima: cabeçada para cima, a laranjinha quase cai.
```

**Bloco 2 → `ref_golpes_2.png` (chão e ar)**
```text
A) Golpe para baixo: pisão de sumô, levanta a perna bem alto e bate o chinelo no chão.
B) Aéreo neutro: vira uma bola, abraçando os joelhos, e gira no ar.
C) Aéreo para a frente: tapa duplo para a frente com as duas mãos.
```

**Bloco 3 → `ref_golpes_3.png` (aéreos)**
```text
A) Aéreo para trás: bundada para trás (de costas, empurra o quadril).
B) Aéreo para cima: bate as duas mãos espalmadas para cima, como palmas.
C) Aéreo para baixo: cai sentado com tudo, de bunda para baixo.
```

**Bloco 4 → `ref_especiais.png` (especiais)**
```text
A) Especial neutro: barrigada carregada; quadros: meditando de olhos fechados enchendo a barriga, barriga enorme, barrigada para a frente.
B) Especial lateral: abraço de capivara; quadros: braços abertos avançando, abraço apertado, arremessa por cima do ombro.
C) Especial para cima: pulo de "bomba" na piscina; quadros: agachado, subindo com os joelhos abraçados, caindo de bomba.
D) Especial para baixo: senta com tudo no chão e faz onda de choque; quadros: pula um pouco, sentando no ar, impacto com poeira.
```

**Bloco 5 → `ref_extras.png` (agarrar, defesa e vitória)**
```text
A) Agarrão: estica os dois braços abertos e abraça.
B) Arremesso para a frente e para trás (2 quadros cada).
C) Defesa: se encolhe atrás da toalha esticada como escudo.
D) Pendurado na borda e subindo na plataforma com esforço (3 quadros).
E) Vitória: toma um gole de água de coco, impassível (3 quadros).
```

- [ ] Os 3 quadros de cada golpe têm o personagem do mesmo tamanho.
- [ ] O impacto é bem esticado e exagerado (é o que faz o golpe "pesar").
